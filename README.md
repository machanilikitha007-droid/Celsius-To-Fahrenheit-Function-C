# Celsius to Fahrenheit Using Function

This program converts a temperature from Celsius to Fahrenheit using
a function that returns the converted value.

## File

temperature_function.c

## Concepts Used

- Function declaration
- Function definition
- Function parameter
- Return value
- Floating-point calculation

## How to Run

gcc temperature_function.c -o temperature_function
./temperature_function

## Sample Output

Enter temperature in Celsius: 25
Temperature in Fahrenheit = 77.00
